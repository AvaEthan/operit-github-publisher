# GitHub 发布器 (Operit2)

> 把已安装的 Skill / MCP 一键发布到 GitHub。Operit2 版改用平台原生数据源（skill/mcp CLI），内置 Token 配置与校验、仓库自动创建、文件并发推送与 Release 资产上传，并保留侧边栏控制台。

- ToolPkg ID：`com.operit.github_publisher`
- 版本：`2.0.2`
- API：`2.0.0`
- 安装包：[下载](https://github.com/AvaEthan/operit-github-publisher/releases/download/v2.0.2/gp2.toolpkg)

## 安装

下载 Release 中的 `.toolpkg`，在 Operit 里用「导入插件包」安装，或执行：

```
operit2 package import <下载后的路径>
operit2 package enable <子包 id>
```
